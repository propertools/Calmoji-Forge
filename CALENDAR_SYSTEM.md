# 🧿 Calendar System

## Reference Layers (immutable — toggle on to plan, off to work)

| Calendar | Use |
|----------|-----|
| 📅 Semester Phases | Seasonal arc — know what mode you're in |
| 🧠 Focus Blocks | Daily palette — copy into 🎯 to claim time |
| 🕒 Meeting Slots | Bookable windows by city/tz — copy into 🤝 or 🔄 to book |

## Working Calendars

| Calendar | Use |
|----------|-----|
| 🎯 Focus — Claimed | Deep work you've committed to |
| 🤝 Meetings — One-off | Single meetings, booked from 🕒 |
| 🔄 Meetings — Recurring | Collaborations that earned a cadence |

## Life

| Calendar | Use |
|----------|-----|
| 👧 Daughter | Non-negotiable |
| ✈️ Travel | Non-negotiable |
| 🛠️ Everyday Stuff | Your life maintenance (default calendar) |
| 🫂 Other People's Stuff | Favours, errands, things you're doing for others |

## Compliance

| Calendar | Use |
|----------|-----|
| 🇧🇪 Hard Deadlines | Regulatory, legal, immovable dates |
| 🇧🇪 Financial Prep | Tax, invoicing, compliance prep |

## Workflow

1. **Plan:** Toggle on 🧠 and 🕒. Scan the week.
2. **Claim focus:** Copy a focus block → 🎯. Rename it.
3. **Book a meeting:** Copy a meeting slot → 🤝 or 🔄. Add name, Zoom, send.
4. **Calmoji layers stay untouched.** They regenerate cleanly each year.
